# About Additional Code

[`loswors_install.iss`](loswors_install.iss) - code for `Inno Setup Compiler 6.7.2`, compiles an installer based on a single file by relative path `build_source\Loswors_vX.X.X.exe`, writes the output to a relative file path `Output\Loswors_WIN_Installer_vX.X.X.exe`. `Windows 10 tested only`.

[`loswors_save_file_v1.hexpat`](loswors_save_file_v1.hexpat) - pattern used for `ImHex` to analyze and visualize the `.lwrs` file format `v1.0.0` - `v1.0.1`.
