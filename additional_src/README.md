# About Additional Code


[`install_v1.0.0.iss`](install_v1.0.0.iss) - code for `Inno Setup Compiler 6.7.2`, compiles an installer based on a single file by relative path `build_source\Loswors_v1.0.0.exe`, writes the output to a relative file path `Output\Loswors_WIN_Installer_v1.0.0.exe`. `Windows 10 tested only`.


[`loswors_save_file_v1.0.0.hexpat`](loswors_save_file_v1.0.0.hexpat) - pattern used for `ImHex` to analyze and visualize the `.lwrs` file format `v1.0.0`.
